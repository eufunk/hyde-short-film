# KI-Bildprompts — Sequenz 02

Hinweis: Die Prompts sind auf Deutsch verfasst (auf Wunsch). Frühere Fassungen dieses Projekts nutzten Englisch, weil aktuelle Bild-/Videomodelle (Gemini, Midjourney, SDXL, Flux, Runway, Kling, Luma) damit oft zuverlässiger arbeiten — bei schwächeren oder ungenauen Ergebnissen lohnt sich testweise die Rückübersetzung ins Englische. Die Charakterbeschreibung stammt aus [`charakterbibel/dr-henry-jekyll.md`](../../charakterbibel/dr-henry-jekyll.md) und sollte in jedem Prompt mit Figur wiederverwendet werden. Style-Suffix am Ende jedes Prompts konstant halten für visuelle Kohärenz.

**Gemini-Hinweis:** Konkreter Ablauf (Referenzbild-Chat, Negative-Block) steht in [`prompts/gemini-workflow.md`](../../prompts/gemini-workflow.md). Das Seitenverhältnis 16:9 wird in Gemini über die UI-Einstellung gewählt, nicht über einen Textparameter wie bei Midjourney.

**Konstanter Style-Suffix (an jeden Prompt anhängen):**
`Aufnahme mit ARRI Alexa, 35-mm-Anamorphot-Objektiv, kinoreife Farbgebung, gedämpfte Petrol-Bernstein-Palette, dezentes Filmkorn, geringe Schärfentiefe, fotorealistisch, hohe Detailtiefe, stimmungsvolle atmosphärische Beleuchtung, Filmstandbild im psychologischen Horror-Stil, Seitenverhältnis 16:9`

---

### Shot 01 — Establishing Exterior
```
Weitwinkel-Einstellung aus niedrigem Winkel auf ein altes Industriegebäude aus rotem Backstein aus dem 19. Jahrhundert bei Nacht, die meisten Fenster dunkel, ein einzelnes Kellerfenster leuchtet warmgelb, starker Regen fällt, nasse Straße reflektiert Licht, entfernte Gewitterwolken, kalte, blaue Nachtstimmung, filmische Establishing-Einstellung
```

### Shot 02 — Korridor
```
Enger unterirdischer Institutskorridor, freiliegende Rohre entlang der Decke, flackerndes Leuchtstoffröhrenlicht am Ende, eine halb geöffnete Stahltür, durch die warmes Licht dringt, feuchte Betonwände, leerer Flur, Dolly-Perspektive aus niedrigem Winkel, angespannte Atmosphäre
```

### Shot 03 — Labor Establishing
```
Weite Innenaufnahme eines Kellerlabors, das alte gefliestes Mauerwerk und freiliegende Rohre mit moderner Laborausstattung kombiniert — Zentrifuge, Kühlschrank mit Glastür, ein einzelner Schreibtisch, beleuchtet von einer warmen Schreibtischlampe als einzige Lichtinsel in einem ansonsten dunklen Raum, Regen sichtbar an einem kleinen hochgelegenen Fenster, ein Mann im weißen Laborkittel sitzt von hinten gesehen am Schreibtisch, stimmungsvolle atmosphärische Komposition
```

### Shot 04 — Jekyll Portrait
```
Halbnahe Einstellung, frontaler Dreiviertelwinkel, [Charakterbeschreibung Dr. Henry Jekyll einfügen], sitzt an einem lampenbeleuchteten Schreibtisch, warmes Licht von unten-vorne, kalte Reflexion auf seiner Brille, erschöpfter, kontrollierter Ausdruck, blickt auf Papiere hinab
```

### Shot 05 — Insert Strichliste
```
Extreme Nahaufnahme, Insert einer handgeschriebenen Strichliste auf liniertem Papier, sechs Striche, alle durchgestrichen, hartes Schreibtischlampenlicht von oben, geringe Schärfentiefe, die Finger eines Mannes berühren sanft das Papier am Bildrand
```

### Shot 06 — Insert Fläschchen
```
Extreme Nahaufnahme eines kleinen Glasfläschchens, gefüllt mit bernsteinfarbener Flüssigkeit, ein handgeschriebenes Papieretikett mit der Aufschrift „07", eine alte, abgenutzte Glasspritze mit Metallnadel liegt daneben, warmes Lampenlicht bricht sich in der Flüssigkeit, geringe Schärfentiefe, eine unscharfe Hand kommt ins Bild
```

### Shot 07 — Diktiergerät
```
Halbnahe Profil-Einstellung, [Charakterbeschreibung Dr. Henry Jekyll einfügen], drückt einen Knopf an einem alten schwarzen analogen Diktiergerät auf dem Schreibtisch, seitliches Lampenlicht erzeugt eine scharfe Schattenlinie über sein Gesicht, intensiver, fokussierter Blick, Regen schwach im Hintergrund sichtbar
```

### Shot 08 — Anspannung
```
Nahaufnahme, frontales Porträt, [Charakterbeschreibung Dr. Henry Jekyll einfügen], angespannte Kiefermuskeln, leicht glänzende Augen, warmes Unterlicht mit halbem Gesicht im Schatten, kontrollierte emotionale Zurückhaltung, Labor sanft unscharf im Hintergrund
```

### Shot 09 — Spiegelbild im Fenster
```
Halbnahe Einstellung über die Schulter zu einem dunklen, regenverschmierten Fenster, schwache Reflexion von [Charakterbeschreibung Dr. Henry Jekyll einfügen] im Glas sichtbar, reglos, kaltes blaues Außenlicht mischt sich mit warmem Innenlampenlicht, Regentropfen auf der Glasoberfläche sichtbar
```

### Shot 10 — Entschlossenheit
```
Nahaufnahme, frontales Porträt, [Charakterbeschreibung Dr. Henry Jekyll einfügen], Augen geschlossen, öffnen sich, Ausdruck wechselt von Zögern zu stiller Entschlossenheit, konstantes warmes Lampenlicht, Schreibtisch sanft unscharf hinter ihm
```

### Shot 11 — Injektion Detail
```
Extreme Nahaufnahme, Insert eines Unterarms mit einem Stauschlauch oberhalb des Ellbogens, eine alte Metallnadel einer Spritze berührt die Haut der Armbeuge, hartes Seitenlicht betont die angespannte Hauttextur, dunkler unscharfer Hintergrund, realistisches medizinisches Detail, kein Blut
```

### Shot 12 — Schlussbild
```
Halbnahe Einstellung, Frontalwinkel, [Charakterbeschreibung Dr. Henry Jekyll einfügen], lehnt sich mit geschlossenen Augen zurück, eine Leuchtstoffröhre flackert, dann öffnen sich die Augen und blicken zu einem dunklen Fenster, wo sein eigenes Spiegelbild einen Sekundenbruchteil verzögert und leicht abweichend erscheint, subtiles unheimliches Falschsein, konstantes warmes Lampenlicht, Regen und Dunkelheit jenseits der Scheibe, beunruhigende stille Anspannung, keine sichtbare Verwandlung
```
