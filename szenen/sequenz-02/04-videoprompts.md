# KI-Videoprompts — Sequenz 02

Hinweis: Prompts auf Deutsch (auf Wunsch), formuliert für Bild-zu-Video-Tools (Veo, Runway Gen-3/4, Kling, Luma Dream Machine, Pika). Jeder Prompt geht von dem entsprechenden Bild-Prompt aus [`03-bildprompts.md`](03-bildprompts.md) als Startframe aus. Bewegungen bewusst subtil und realistisch halten — keine schnellen Kamerafahrten, keine übertriebene Motion. Für Veo: siehe [`prompts/gemini-workflow.md`](../../prompts/gemini-workflow.md).

---

### Shot 01 — Establishing Exterior (4 s)
```
Statische Weitwinkel-Einstellung, starker Regen fällt durchgehend, dezente Parallaxe der Regentropfen im Vordergrund, ein entferntes Blitzflackern einmal schwach in den Wolken, keine Kamerabewegung, realistische Regenphysik, kalte Nachtstimmung
```

### Shot 02 — Korridor (3 s)
```
Langsame Vorwärts-Dolly-Bewegung auf Augenhöhe durch einen dämmerigen unterirdischen Korridor, Leuchtstofflicht flackert zweimal, Dampf oder Kondenswasser schwach an den Rohren sichtbar, gleichmäßige, realistische Kamerageschwindigkeit im Gehtempo, keine Figuren sichtbar
```

### Shot 03 — Labor Establishing (5 s)
```
Statische Weitwinkel-Einstellung, nur dezente ambiente Bewegung: Regen rinnt am kleinen hochgelegenen Fenster herab, schwacher Dampf von den Geräten, die Schultern des sitzenden Mannes heben und senken sich langsam beim Atmen, keine Kamerabewegung, ruhige, schwere Atmosphäre
```

### Shot 04 — Jekyll Portrait (4 s)
```
Statische halbnahe Einstellung, dezente natürliche Atembewegung, langsames Blinzeln, Augen wandern nach unten zu den Papieren, minimale Kopfbewegung, realistische menschliche Mikrobewegung, keine Kamerabewegung
```

### Shot 05 — Insert Strichliste (3 s)
```
Statische extreme Nahaufnahme, langsamer Fokuswechsel von der Strichliste zur Schärfe, Finger gleiten langsam ins Bild und berühren sanft den Papierrand, dezentes natürliches Zittern der Hand, keine Kamerabewegung
```

### Shot 06 — Insert Fläschchen (4 s)
```
Sehr langsamer Push-in-Zoom auf das Fläschchen, die Flüssigkeit darin bleibt reglos, eine weiche, unscharfe Hand kommt vom Bildrand herein und hebt die daneben liegende Spritze auf, realistische Glasreflexionen, langsame, bedächtige Bewegung
```

### Shot 07 — Diktiergerät (5 s)
```
Statische halbnahe Profil-Einstellung, ein Finger drückt mit einer kleinen mechanischen Klickbewegung einen physischen Knopf am Diktiergerät, dezente Kieferanspannung, die Augen bleiben starr und unblinzelnd auf das Gerät gerichtet, keine Kamerabewegung, realistische menschliche Reglosigkeit
```

### Shot 08 — Anspannung (6 s)
```
Statisches Nahaufnahme-Porträt, langsam aufbauende, dezente Gesichtsanspannung im Kiefer, ein einzelnes langsames Blinzeln, die Augen glänzen leicht, die Lippen öffnen sich leicht, um die Zeile „Nicht heute Nacht" zu sprechen, ganz leichte Handheld-Atembewegung, realistische Mikroexpressionen, keine übertriebene Emotion
```

### Shot 09 — Spiegelbild im Fenster (4 s)
```
Statische Über-die-Schulter-Einstellung, Regentropfen rinnen langsam an der Fensterscheibe herab, die schwach reflektierte Gestalt bleibt reglos und spiegelt exakt den Atem der realen Figur, dezentes ambientes Lichtflackern durch einen entfernten Blitz draußen, keine Kamerabewegung
```

### Shot 10 — Entschlossenheit (5 s)
```
Statisches Nahaufnahme-Porträt, Augen geschlossen, dann langsam geöffnet, der Ausdruck wechselt subtil von Anspannung zu stiller Entschlossenheit, die Lippen bewegen sich leicht, um „Doch. Heute Nacht." zu sprechen, natürliches Blinzeln und Atmen, keine Kamerabewegung
```

### Shot 11 — Injektion Detail (4 s)
```
Statische extreme Nahaufnahme auf den Unterarm, die Nadelspitze berührt sanft die Haut, sehr leichte realistische Hauteindellung, die Hand bleibt weitgehend ruhig mit einem leichten natürlichen Zittern, keine Kamerabewegung, keine übertriebenen Flüssigkeits- oder Blut-Effekte
```

### Shot 12 — Schlussbild (5 s)
```
Statische halbnahe Frontal-Einstellung, die Figur lehnt sich zurück und schließt die Augen, die Leuchtstofflampe flackert einmal mit einem kurzen Frame nahezu vollständiger Dunkelheit, die Augen öffnen sich und wenden sich dem Fenster zu, die reflektierte Gestalt im Glas bewegt sich mit einer kaum wahrnehmbaren Verzögerung von wenigen Frames gegenüber der realen Figur, nur eine subtile unheimliche Timing-Abweichung, keine Verformung, keine sichtbare Verwandlung, beunruhigende Reglosigkeit, hält auf dem letzten Frame
```
